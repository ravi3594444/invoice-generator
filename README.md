# Invoice Generator

Micro-invoicing and contract portal for independent creators, freelancers, students and gig
workers. Create a clean invoice or micro-contract in a minute, share it as a link or PDF, get paid
through your own UPI / card / PayPal links, and let polite automated reminders chase the money.

Runs in any browser on desktop and phone, installable as a PWA. Free to run on free tiers.
