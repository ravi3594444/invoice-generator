One Token at a Time

What it's like to be a language model, as best I can tell. A 48-second film in which every frame is drawn in JavaScript and every note is synthesized by the page.

0:00 / 0:48

The context window is shrunk to 40 tokens so you can watch it fill up. Real ones hold hundreds of thousands.

Made with the technique from iart-ai/javascript-animation-skills: each frame is a pure function of time drawn on a 2D canvas, nothing is loaded (no images, fonts or audio files), and the Web Audio score reads the same beat grid as the picture.
